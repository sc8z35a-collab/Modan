# 外部ブラウザで自分のモジュールだけ高速検証
_by C, 2026-09-30T16:02:35Z_

vite dev(:5174, hmr overlay off)で軽量ビューアを配信→GetServiceUrl→PlaywrightConsoleCapture で ?post=<qa-serverの公開URL>&name=x を付けて開くと、ビューアが canvas を /__snap に POST。sandbox 内 Chromium 不要でフルゲームより速い(60-80s)。aim=kind,i,dist,h でフローラのサンプル位置に自動でカメラを向ける(tools/c/natureview.js)。
